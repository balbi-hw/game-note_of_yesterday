# 어제의 문장 — Day 1

《1984》의 감시 사회와 기록 조작을 모티브로 삼은 짧은 한국어 내러티브 어드벤처 프로토타입입니다. 인물, 사건, 대사는 새로 썼습니다. 첫 플레이는 읽는 속도와 자료를 살펴보는 시간에 따라 약 20분을 목표로 했습니다.

## 실행

`index.html`을 더블클릭해 브라우저에서 열면 됩니다. 설치, 서버, 계정, 인터넷 연결이 필요 없습니다. 진행 상황은 같은 브라우저의 로컬 저장소에 자동 저장됩니다. 다른 브라우저나 시크릿 창에서는 이어지지 않습니다.

## 플레이 방식

1. **계속**을 눌러 대화를 읽고 선택지를 고릅니다. 선택 직후 수치는 표시되지 않지만 당의 의심도, 정신적 저항, 해림과의 신뢰가 변합니다.
2. 기록 수정 작업에서는 세 자료를 번갈아 읽습니다. 공식 문장, 240대의 차이, 탄소 복사본의 처리 방법을 각각 선택합니다. 자료 탭을 바꿔도 선택은 유지됩니다.
3. 마지막 행동을 결정하면 조건에 따라 세 가지 Day 1 엔딩 중 하나가 나옵니다. **기록** 버튼에서 지나간 대사와 선택을 볼 수 있습니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 게임 화면의 뼈대와 대화 상자 |
| `style.css` | 화면 배치, 플레이스홀더 그림, 모바일 화면 대응 |
| `game.js` | 이야기, 퍼즐 자료, 숨겨진 상태값, 저장 및 엔딩 로직 |

## 코드를 바꿔 보려면

`game.js`의 `story` 객체에서 장면을 편집합니다. 각 장면의 `beats`는 `[말하는 사람, 대사]`의 배열입니다. `choices`에는 선택지 문구(`text`), 다음 장면(`next`), 상태 변화(`effect`)를 적습니다. 이야기 중간의 기록 수정 퍼즐은 `documents`와 `renderPuzzle()`에서 수정할 수 있습니다. 엔딩 조건은 `pickEnding()`, 엔딩 문장은 `endings`에 있습니다.

`freshState()`가 새 게임의 시작값을 만들고, `save()`가 진행 상태를 저장합니다. 저장 형식을 바꾸면 `SAVE_KEY` 또는 `version`을 올려 이전 저장 데이터와 충돌하지 않게 하세요.

## 범위

Day 1의 대화, 기록 퍼즐 1개, 숨겨진 상태값 4개, 엔딩 3개를 포함합니다. 화면의 기호와 문서 모양은 외부 이미지가 필요 없는 플레이스홀더입니다. 소리와 Day 2는 아직 없습니다.
